# Generated Docs

This folder can contain generated markdown from `tools/Sts2Inspector`.

Generated docs are allowed to be committed if they are useful.

Recommended generated files:

```text
RunState.md
Player.md
StartRunLobby.md
CombatManager.md
RunSaveManager.md
RunHistorySaveManager.md
ProgressSaveManager.md
Hook.md
RunLobby.md
BaseLib.md
```

Do not treat generated docs as confirmed behavior. They show API shape, not runtime semantics.
